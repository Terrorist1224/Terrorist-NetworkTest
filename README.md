# Terrorist NetworkTest

Terrorist NetworkTest 是面向 Windows 的桌面网络测速工具。它支持下行、上行和上下行并行测速，并提供暂停续测、历史记录及托盘后台运行。

## 功能

- 下行、上行和并行三种测速规则，可选择 0（自动）、4、8、16 或 32 个线程；自动模式固定使用 8 个线程，并行模式每个方向各使用所选线程数。
- 内置和彩云下行通道；测速网国内节点提供下行及配对上传地址。也可以添加自定义下载地址。
- 节点下拉框提供自动选择和手动选择。自动模式选择当前延迟最低且不高于 300 ms 的国内节点，只在待机时切换；测速和暂停期间保持当前节点。手动列表仅显示延迟不高于 300 ms 的国内及自定义通道；测速网节点按省市、运营商和节点编号搜索，100 ms 以内为绿色，101–300 ms 为黄色。上行和并行模式只显示提供上传地址的国内节点。
- 国内节点每分钟更新一次延迟；测速网通过 WebSocket 探测，其他通道使用 HTTP 首字节延迟。
- 主界面分组显示下行、上行和合计的速度、带宽及流量，并排展示上下行速度图；错误和警告以可点击关闭的窗口浮窗显示，不占用页面布局空间。
- 自动停止条件可选限量（GB）、限时（分钟）或不限制。
- 暂停后可修改线程和停止条件再继续。累计流量保留；限时只计算实际测速时间，暂停时钟不计入。
- 始终显示独立的上下行每秒速度曲线；单方向测速时，另一张图标明本次未测试。实时速度和历史记录按方向分别统计。
- 限量模式下，上行和下行各自使用完整的流量额度；并行时总流量最多可达到该额度的两倍。
- 关闭主窗口后继续在托盘运行。历史记录最多保留最近 20 次测速。

本程序只测量自身发起的测速流量，不统计其他应用的流量。下行按下载响应正文计量；上行按服务端成功接受的上传请求正文计量。计量不含 HTTP 报头、重传及其他程序的流量。

## 安装与升级

在 Windows 10/11 x64 上运行单文件安装程序。自行构建后，文件位于：

```text
release/Terrorist NetworkTest 1.1.0.exe
```

首次安装时可选择目标路径；安装器会在所选位置下创建 `TerroristNetWorkTest` 文件夹，默认只为当前用户安装。不创建桌面或开始菜单快捷方式。

升级时，先从托盘彻底退出程序，再运行新版安装包。安装器始终显示安装路径选择页，并默认填入原安装目录；如果改选其他目录，安装器会把旧目录 `data` 中尚未存在于新目录的文件复制过去。**不要先卸载旧版**，旧版卸载程序可能删除安装目录中的数据。1.1.0 首次启动时会把旧 `data` 迁移到用户配置目录；迁移采用复制方式，旧目录数据会保留。

## 数据与卸载

- 设置、自定义通道、测速记录、Chromium 会话数据、崩溃转储和应用临时文件保存在 `%APPDATA%\TerroristNetWorkTest`。1.1.0 首次启动时会从旧安装目录的 `data` 文件夹迁移这些数据；历史记录最多保留最近 20 条。
- 测速网节点列表按当前网络区域从官网动态加载；节点地址只保存在当前运行内存，不写入本地数据目录。节点响应中的请求元数据不会保存。
- 可通过 Windows“已安装的应用”或安装目录中的 `unins000.exe` 卸载。卸载会删除程序文件和应用安装记录，用户配置目录中的数据会保留；如需彻底清理，可在卸载后手动删除 `%APPDATA%\TerroristNetWorkTest`。
- 安装器会短暂使用 Windows 临时目录释放组件。打包脚本要求本机临时目录位于 C 盘。正常安装完成后，安装器创建的临时目录会清理；卸载器自身的临时副本可能按照 [Inno Setup 的说明](https://jrsoftware.org/isfaq.php)保留到下次 Windows 重启。
- 如果手动移动已安装的程序，安装器记录的旧路径不会自动更新。用户数据保存在独立的用户配置目录中，不需要随程序文件移动。

## 开发与构建

开发环境为 Windows 10/11 x64 和 Node.js 22.12 或更新版本。克隆项目后运行：

```powershell
npm ci
npm run dev
```

也可以在 Windows 上双击根目录的 `start-dev.cmd` 启动开发版。开发版数据保存在 `.tmp/user-data/`。

构建并生成安装程序：

```powershell
npm run package:win
```

脚本会先运行类型检查和测试，再构建应用并使用 [Inno Setup 安装脚本](installer/setup.iss)生成单文件安装程序，输出到 `release/`。打包需要本机安装 Inno Setup 7 编译器，且 Windows 临时目录必须位于 C 盘。发布新版本时，需要同步更新 `package.json`、`package-lock.json`、`src/shared/version.ts`、`src/renderer/index.html`、`installer/setup.iss` 和 `scripts/package-win.ps1` 中的版本号，再更新[更新日志](CHANGELOG.md)。本项目没有代码签名证书；Windows 可能对未签名安装程序显示安全提示。

常用命令：

| 命令                  | 用途                                   |
| --------------------- | -------------------------------------- |
| `npm run dev`         | 启动开发版                             |
| `npm run typecheck`   | 检查 TypeScript 和 Vue 类型            |
| `npm test`            | 运行测试                               |
| `npm run build`       | 构建 Electron 应用文件，不生成安装程序 |
| `npm run package:win` | 检查、构建并打包 Windows x64 安装程序  |

## 项目结构

```text
src/main/       Electron 主进程、测速引擎、设置和历史记录
src/preload/    渲染进程的受控 IPC 接口
src/renderer/   Vue 界面、图表和历史记录页面
src/shared/     主进程与渲染进程共用的数据类型
tests/          测速与计量测试
resources/      托盘与应用图标
installer/      Inno Setup 安装程序脚本
scripts/        打包和后台性能检查脚本
```

## 通道与服务使用

内置下行通道和测速网节点使用相应服务当前公开的测试资源。服务商可能变更地址、限制并发或限制流量；测速前请确认自己有权使用这些资源，并遵守对应服务条款。自定义通道仅支持 HTTP 或 HTTPS 下载地址。

测速网节点延迟通过官网提供的 WebSocket ping 测量；其他国内通道通过 HTTP Range 请求测量至首个响应字节。这些延迟都不是 ICMP ping。清单更新和节点探测遵循系统当前网络、代理和 TUN 路由；如果希望国内节点直连，请在代理客户端中将相应测速域名或 IP 配置为 DIRECT。程序不会自行绕过系统代理或 TUN。
